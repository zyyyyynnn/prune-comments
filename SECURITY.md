# Security

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/zyyyyynnn/prune-comments/security/advisories/new).

Include the affected version or commit, host agent, reproduction steps, and impact. Do not open a public issue for secrets, exploit details, or private session data.

The latest `main` is the supported version. This repository contains agent instructions; the primary security boundary is preventing unsafe or over-broad modification of a caller's repository.
